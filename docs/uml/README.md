## 2. 渲染方式

### 2.1 命令行渲染（推荐用于批量出图）

先安装 PlantUML（需要 Java 运行环境，JDK 17 或以上），然后在项目根目录执行：

```bash
java -jar plantuml.jar -charset UTF-8 -tpng docs/uml/*.puml
```

渲染为 SVG（课程报告插入矢量图更清晰）：

```bash
java -jar plantuml.jar -charset UTF-8 -tsvg docs/uml/*.puml
```

若已把 PlantUML 加入 PATH，也可直接：

```bash
plantuml -charset UTF-8 -tpng docs/uml/*.puml
```

渲染结果默认与源文件同目录、同文件名，仅扩展名改为 png 或 svg。

### 2.2 VS Code 插件渲染

1. 在扩展市场安装「PlantUML」插件（jebbs.plantuml）；
2. 打开任意 `.puml` 文件，按 `Alt+D`（Windows）打开实时预览；
3. 在预览区右键可导出 PNG/SVG，或点击「Export Current Diagram」；
4. 若图中中文显示为方框，安装 Graphviz 并在插件设置中指定 `plantuml.render` 为 `Local`，同时确认字体支持中文（如 Microsoft YaHei）。

### 2.3 其他工具

- IntelliJ IDEA：安装 PlantUML Integration 插件后，右键 `.puml` 文件即可渲染；
- 支持 PlantUML 的 Markdown 编辑器：将源码包裹在 `plantuml` 代码块中即可预览（本目录保留独立 `.puml` 文件作为唯一事实来源）。

## 4. 编写约定

1. 每个 `.puml` 文件顶部以单引号 `'` 注释声明：图名、撰写成员、版本、对应需求章节。
2. 用例编号规则：`UC_USR_xx`（用户端）、`UC_MER_xx`（商家端）、`UC_ADM_xx`（平台端）、`UC_PUB_xx`（公共），与 SRS 第 7 章追踪矩阵一致。
3. 用例统一使用 `(中文用例名) as 英文别名` 定义，关系引用一律使用英文别名，避免中文与语法符号冲突。
4. 关系语义：`<<include>>` 表示必然复用（如下单必含库存校验与支付）；`<<extend>>` 表示条件触发（如超时触发平台介入）。
5. 活动图角色用「【用户】」「【商家】」「【系统】」「【平台管理员】」前缀标注，便于识别职责归属。
6. 活动图条件分支统一使用 `if (条件?) then (yes) ... else (no) ... endif` 结构，每个分支以 `stop` 收束。
7. 文件统一使用 UTF-8 编码；自然语言使用中文标点，代码与 PlantUML 语法符号使用 ASCII 字符。
8. 版本变更时同步修改文件头注释与本文档的「对应版本」字段。
