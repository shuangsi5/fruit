## 1. 系统概述

「水果交易智能管理系统」是一套面向本地果农与水果经销商的轻量化三端交易系统，覆盖「货源上架 → 客户下单 → 库存管理 → 物流配送 → 售后服务」完整链路。系统在统一后端上提供三套角色视图，并内置两类智能能力：

- **个性化推荐**：按「0.5×购买频次 + 0.3×User-CF 协同过滤 + 0.2×近 30 天热销」混合计算推荐得分；新用户无历史行为时自动使用热销榜兜底，每条推荐附理由标签。
- **临期与损耗预警**：按临期天数（30/7/3 天）与损耗风险（0.2/0.4/0.7）分级，综合等级取各类别最大值，分为正常 / 注意 / 警告 / 严重四级；每日 02:00 全量扫描，商家可查看处理建议。

系统采用模拟支付与模拟物流，不产生真实资金流动，也不对接第三方快递接口，适合教学演示与人工验收。

## 2. 三端角色说明

| 角色 | 角色码 | 主要用途 | 登录后首页 | 侧边栏菜单 |
|---|---|---|---|---|
| 终端消费者 | USER | 浏览商品、下单支付、跟踪订单、申请售后、查看推荐 | `/home` | 无侧边栏，使用顶部导航与个人中心快捷入口 |
| 入驻商家 | MERCHANT | 商品上下架、库存与预警处理、订单发货、售后审核、销售报表 | `/merchant/dashboard` | 工作台、商品管理、库存与预警、订单管理、售后处理、销售报表 |
| 平台管理员 | ADMIN | 商家资质审核、用户账号管理、投诉处理、数据总览 | `/admin/dashboard` | 工作台、商家审核、用户管理、投诉处理、数据总览 |

商家与管理员登录后，左侧显示对应角色菜单（标题为「商家中心」或「平台管理」），用户端则通过顶部导航与个人中心的「快捷入口」跳转各功能页。

## 3. 运行环境与浏览器要求

| 项目 | 要求 |
|---|---|
| 后端服务 | JDK 17 及以上，Spring Boot 3.2.5，默认端口 8080 |
| 数据库 | MySQL 8.0，库名 `fruit_trade_db`，字符集 utf8mb4 |
| 前端 | Vue 3 + Vite 5，开发模式默认端口 5173 |
| 浏览器 | Chrome、Edge 最近两个大版本 |
| 分辨率 | 1366×768 及以上；移动端浏览器支持响应式布局 |
| 浏览器设置 | 需启用 JavaScript 与本地存储（localStorage 用于保存登录 Token） |

访问地址：开发模式为 `http://localhost:5173`；生产部署（Nginx 同域）为部署服务器地址，后端接口经 `/api` 反向代理到 8080 端口。

## 4. 登录与注册

### 4.1 真实演示账号（重要）

登录页的「演示账号（点击自动填充）」区域提供三个快捷按钮：`用户端 user01`、`商家端 merchant01`、`平台端 admin`，已与种子数据一致，可直接点击填充；也可手动输入以下账号：

| 角色 | 真实账号 | 密码 | 说明 |
|---|---|---|---|
| 平台管理员 | `admin` | `123456` | 进入平台工作台 |
| 入驻商家 | `merchant01` | `123456` | 鲜果优选，已审核营业中 |
| 入驻商家 | `merchant02` | `123456` | 绿园鲜果，已审核营业中 |
| 普通用户 | `user01` | `123456` | 张三，含购物车与多状态订单 |
| 普通用户 | `user02` | `123456` | 李四 |
| 普通用户 | `user03` | `123456` | 王五 |

所有演示账号密码统一为 `123456`。

【截图位】登录页：左侧为品牌区与演示账号快捷区，右侧为「用户名 / 手机号」「密码」输入框与「登 录」按钮。建议在此处标注真实账号对照表。

### 4.2 登录操作步骤

1. 打开系统地址，进入登录页，页面标题为「水果交易智能管理系统」。
2. 在「用户名 / 手机号」输入框输入真实账号（如 `user01`）。
3. 在「密码」输入框输入 `123456`。
4. 点击「登 录」按钮。
5. 系统按角色自动跳转：USER 进入 `/home`，MERCHANT 进入 `/merchant/dashboard`，ADMIN 进入 `/admin/dashboard`。
6. 若此前访问过受保护页面，登录后自动回到该页面。

登录失败时，输入框下方会显示红色错误提示，常见原因见第 11 节 FAQ。

### 4.3 注册操作步骤

1. 在登录页底部点击「立即注册」，进入「注册账号」页。
2. 选择「注册角色」：普通用户（USER）或入驻商家（MERCHANT）。
3. 依次填写「用户名」「真实姓名」「手机号」「密码」「确认密码」。
4. 若注册商家角色，还需填写「店铺名称」，可选填「营业执照号（选填）」。
5. 提交后系统提示注册成功；商家角色初始为「待审核」，审核通过前无法上架商品。
6. 点击页面底部「立即登录」返回登录页。

> 注册商家后请联系平台管理员在「商家审核」中执行「通过」，否则商家端操作会提示未通过审核。

### 4.4 退出登录

点击页面右上角的「退出登录」，本地登录状态被清除并跳转回登录页。

## 5. 用户端操作指引

### 5.1 浏览分类与搜索商品

1. 登录成功后进入首页，页面顶部横幅为「新鲜水果，产地直达」。
2. 在「商品分类」区点击任一分类（如「应季水果」「热带水果」「浆果类」），进入分类商品列表；点击「查看全部 >」进入「全部商品」页。
3. 在首页搜索框（提示文字「搜索想买的水果，如：赣南脐橙」）输入关键字，点击「搜索」或按回车，进入「全部商品」页并展示匹配结果。
4. 在「全部商品」页可通过分类、价格区间、排序条件组合筛选，点击「筛选」生效；点击「清空筛选」恢复全部商品。

首页还包含「为您推荐」（标注「基于您的偏好智能推荐」）与「热销水果」两个商品区，可直接点击商品卡片进入详情。

### 5.2 查看商品详情

1. 在列表或首页点击商品卡片，进入商品详情页。
2. 页面展示商品名称、副标题、价格与原价、单位规格、产地、库存、生产日期、保质期天数、累计销量与「商品描述」。
3. 在「数量」区域点击「-」「+」调整购买数量，数量不得超过可售库存。
4. 库存充足时，「加入购物车」与「立即购买」按钮可用；库存为 0 时按钮显示「已售罄」并置灰。
5. 页面下方「相关推荐」展示同类与协同过滤推荐商品，点击可继续浏览。

### 5.3 管理购物车

1. 点击「加入购物车」后，进入顶部导航的「购物车」（或地址 `/cart`）。
2. 页面标题为「我的购物车」，括号内显示商品件数。
3. 勾选「全选」或单个商品前的复选框，底部实时显示「已选 N 件商品」与合计金额。
4. 通过数量「+」「-」调整数量；超过库存时会提示「库存不足，最多可购买 N 件」。
5. 点击条目右侧的删除操作可移除商品；空购物车显示「购物车还是空的，去挑选新鲜水果吧」，可点击「去逛逛」返回首页。
6. 勾选至少一件商品后，点击「去结算」进入确认下单页。

### 5.4 结算与提交订单

1. 进入「确认下单」页，首先在「收货地址」区选择地址（点击地址卡片即可选中，默认地址自动选中）。
2. 如需新增地址，点击「+ 新增收货地址」，填写「收货人」「手机号」「省」「市」「详细地址」，可勾选「设为默认地址」，点击「保存地址」。
3. 在「商品清单」区核对商品、单价、数量与小计。
4. 在「订单备注（选填）」填写备注，如「尽快发货」。
5. 在「支付方式」中选择「模拟微信支付」或「模拟支付宝」。
6. 核对「应付金额」后点击「提交订单」。系统按商品快照价格重新计算金额并预占库存，生成待支付订单。

### 5.5 模拟支付与取消订单

1. 提交订单后进入订单详情页，或到「我的订单」找到待支付订单点击「去支付」。
2. 在订单详情的支付区域点击「模拟微信支付」或「模拟支付宝」。
3. 支付成功后订单状态变为「待发货」，生成支付流水，商家端同步可见。
4. 若暂不支付，可点击「取消订单」，订单变为「已取消」并释放预占库存。
5. 待支付订单需在 30 分钟内完成支付，超时将自动取消并释放库存。

### 5.6 跟踪订单状态

1. 点击顶部导航「我的订单」进入订单列表，页面标题为「我的订单」。
2. 可按状态筛选，点击「搜索」查询；列表展示订单号、状态、金额、下单时间与商品预览。
3. 点击「查看详情」进入订单详情页，可查看：
   - 「订单进度」时间线；
   - 「物流信息」区，展示运单号、承运商与物流节点时间线；
   - 「商品明细」与「收货信息」。
4. 订单状态共六种：0 待支付、1 待发货、2 运输中、3 已完成、4 已取消、5 售后中。
5. 运输中订单可点击「确认收货」，订单变为「已完成」；完成后 7 天内可申请售后。

### 5.7 申请售后

1. 在已完成订单的详情页点击「申请售后」，或到「我的售后」页从订单列表进入，页面标题为「申请售后」。
2. 「订单编号」自动带入。
3. 在「售后类型 *」中选择：仅退款、退货退款、换货。
4. 在「申请商品」中选择要售后的商品明细。
5. 填写「退款金额 *」「申请原因 *」，可在「凭证图片（选填，输入图片URL，多个用逗号分隔）」填写图片地址。
6. 提交后生成售后单，状态为「待审核」，订单状态变为「售后中」。
7. 在「我的售后」页可查看处理进度；点击「返回订单」回到订单列表。

> 售后仅可在订单完成后 7 天内申请，超时会被拒绝。

### 5.8 查看个性化推荐

1. 登录后在首页「为您推荐」区查看系统推荐商品，每条推荐附理由标签（如基于购买频次、猜你喜欢、热销推荐）。
2. 新用户无历史购买记录时，该区展示热销兜底商品。
3. 商品详情页底部的「相关推荐」展示与当前商品相关的推荐结果。
4. 点击任一推荐商品卡片可进入商品详情。

### 5.9 个人中心与收货地址

1. 点击顶部导航进入「个人中心」，可查看「账户信息」。
2. 在「快捷入口」中可快速跳转「我的订单」「我的售后」「浏览商品」「个性推荐」。
3. 收货地址可在「确认下单」页的新增地址区管理；设置默认地址后，下单时自动选中。

## 6. 商家端操作指引

商家登录后左侧菜单为「工作台」「商品管理」「库存与预警」「订单管理」「售后处理」「销售报表」。

### 6.1 商家工作台

进入 `/merchant/dashboard`，页面标题为「商家工作台」，展示待处理订单、预警数量等概览指标，以及「近 7 日销售趋势」图。可点击「管理商品」「查看订单」「详细报表 >」「前往处理 >」快捷跳转对应模块。

### 6.2 商品上下架与编辑

1. 点击左侧「商品管理」，页面标题为「商品管理」。
2. 点击「+ 上架新商品」打开表单，依次填写：
   - 「商品名称 *」「分类 ID *」（可填 11 柑橘类、12 苹果梨等）
   - 「售价 *」「原价」「单位」「规格」「产地」
   - 「保质期(天) *」「生产日期 *」（不得晚于当前日期）
   - 「库存 *」「安全库存」
   - 「主图 URL *」「商品描述」
3. 点击「保存」完成上架，商品状态为上架，用户端可见。
4. 在列表中点击「编辑」可修改商品信息；历史订单中的商品快照不受影响。
5. 点击「下架」后商品不再对用户展示；点击「重新上架」可恢复。
6. 列表支持按状态与关键字查询，点击「查询」刷新结果。

### 6.3 库存调整与预警处理

1. 点击左侧「库存与预警」，页面标题为「库存与预警」，包含三个标签页：
   - 「库存列表」：展示「商品名称」「当前库存」「锁定库存」「安全库存」「预警等级」「剩余天数」，点击「调整库存」补货或出库。
   - 「预警商品」：展示临期、损耗、库存不足预警，含「预警类型」「预警等级」「说明」，可点击「补货」。
   - 「临期商品」：展示「生产日期」「保质期」「到期日」「剩余天数」「库存」「预警」。
2. 在「调整库存」弹窗中填写「变动量 *（正数为入库，负数为出库）」「变动类型 *」「安全库存」「备注」，点击「确定」。
3. 预警等级说明：0 正常、1 注意、2 警告、3 严重；综合等级取临期、损耗、库存不足三类中的最高值。
4. 系统每日 02:00 全量扫描，库存变动时也会触发增量重算；黄色及以上预警建议在保质期内促销清仓或下架。

### 6.4 订单发货

1. 点击左侧「订单管理」，页面标题为「订单管理」，可按状态与订单号/商品名筛选，点击「查询」。
2. 仅「待发货」订单的操作列显示「发货」按钮；点击后打开发货弹窗。
3. 填写「物流公司 *」（如顺丰速运）与「运单号 *」（如 SF1234567890）。
4. 点击「确认发货」，订单状态变为「运输中」，生成物流记录与首条物流节点，用户端同步可见。
5. 点击「查看详情」可查看订单完整信息。

### 6.5 售后审核

1. 点击左侧「售后处理」，页面标题为「售后处理」，列表展示售后单号、类型、原因、金额、状态、申请时间。
2. 对「待审核」售后单点击「审核」。
3. 填写「处理说明」，点击「审核通过」或「驳回」。
4. 通过后售后单进入「处理中」；驳回后用户可申诉进入平台介入。
5. 处理结果写入审核记录，用户端可见状态变化。

### 6.6 销售报表

1. 点击左侧「销售报表」，页面标题为「销售报表」。
2. 选择开始日期与结束日期，点击「查询」。
3. 查看「销售趋势」图与「热销商品 TOP」表（列：排名、商品名称、销量、销售额）。
4. 报表按支付成功且未退款的订单统计，金额保留两位小数。

## 7. 平台端操作指引

管理员登录后左侧菜单为「工作台」「商家审核」「用户管理」「投诉处理」「数据总览」。

### 7.1 平台工作台

进入 `/admin/dashboard`，页面标题为「平台工作台」，展示关键指标与「平台销售趋势」图，可点击「审核商家」「数据总览」「详细总览 >」快捷跳转。

### 7.2 商家审核

1. 点击左侧「商家审核」，页面标题为「商家审核」，可按审核状态筛选并点击「查询」。
2. 列表列：商家名称、登录账号、联系人、联系电话、营业执照号、审核状态、操作。
3. 对「待审核」商家点击「审核」，查看资质信息并填写「审核意见」。
4. 点击「通过」：商家状态变为「审核通过」，获得商品上架权限；点击「驳回」：状态变为「审核驳回」，商家端可见驳回原因。
5. 已审核商家可点击「详情」查看，点击「关闭」退出弹窗。

### 7.3 用户管理

1. 点击左侧「用户管理」，页面标题为「用户管理」。
2. 可按角色、状态、用户名/手机号关键字筛选，点击「查询」。
3. 列表列：用户名、真实姓名、手机号、角色、状态、注册时间、操作。
4. 通过操作列可启用或禁用用户；禁用后该用户无法登录且原有 Token 失效。
5. 不可禁用当前登录的自身管理员账号。

### 7.4 投诉处理

1. 点击左侧「投诉处理」，页面标题为「投诉处理」，可按状态与类型筛选，点击「查询」。
2. 对投诉可点击「标记处理中」或「关闭投诉」。
3. 在弹窗中填写「处理说明 *」，点击「确定」提交；点击「取消」放弃。
4. 处理状态依次为：0 待处理、1 处理中、2 已处理、3 已关闭。

### 7.5 数据总览

1. 点击左侧「数据总览」，页面标题为「数据总览」。
2. 展示用户数、商家数、订单数、售后数、投诉数等关键指标与「订单与销售额趋势」图。
3. 点击「刷新」重新拉取最新数据。

## 10. 操作提示

1. 金额统一以 `¥` 符号展示并保留两位小数；日期时间统一为 `yyyy-MM-dd HH:mm:ss`。
2. 状态标签使用颜色语义：绿色表示正常/成功，黄色表示提醒，红色表示风险/异常。
3. 表单必填项以红色星号 `*` 标注，输入非法值时会在对应字段下方给出可读提示。
4. 长时间操作（提交订单、生成报表等）按钮会显示「提交中...」「保存中...」等加载态，请勿重复点击。
5. 移动端浏览器会自动切换为响应式布局：侧边栏变为横向可滚动菜单，页面无横向滚动。

## 11. 常见问题 FAQ

**Q1：点击登录页的快捷按钮后登录失败？**
A：一键填充账号已修正为真实账号 `user01`/`merchant01`/`admin`，密码以 `sql/init.sql` 为准。若仍失败，请手动输入：用户 `user01`、商家 `merchant01` 或 `merchant02`、管理员 `admin`。

**Q2：忘记密码怎么办？**
A：本项目为教学演示系统，不提供邮件或短信找回。可使用任一演示账号登录；如需重置，请由管理员在数据库中重新导入 `sql/init.sql`。

**Q3：商家登录后无法上架商品或提示未通过审核？**
A：新注册商家初始状态为「待审核」。请联系管理员用 `admin` 登录，在「商家审核」中对该商家执行「通过」。演示账号 `merchant01` 与 `merchant02` 已审核通过，可直接使用。

**Q4：下单时提示「库存不足」？**
A：所购数量超过可售库存。可在商品详情或购物车减少数量；商家可在「库存与预警」中通过「调整库存」补货后重试。

**Q5：订单为何自动变成「已取消」？**
A：待支付订单超过 30 分钟未支付会自动取消并释放库存。请重新下单并及时点击「模拟微信支付」或「模拟支付宝」。

**Q6：为什么不能申请售后？**
A：仅「已完成」或「售后中」相关订单可申请，且需在完成后 7 天内。已取消、待支付、待发货、运输中订单不可直接申请售后。

**Q7：售后被商家驳回怎么办？**
A：用户可发起申诉，售后单进入平台待介入队列，由管理员强制裁决。裁决结果对用户与商家同时生效。

**Q8：页面打开后空白或按钮无反应？**
A：请确认已启用浏览器 JavaScript 与本地存储；清除浏览器缓存后刷新；开发模式下请确认后端服务已在 8080 端口启动。

**Q9：商品名称显示乱码？**
A：请确认 MySQL 数据库与表使用 utf8mb4 字符集，且连接参数包含 `characterEncoding=utf8`。重新导入 `sql/init.sql` 可恢复。

**Q10：首页「为您推荐」没有内容？**
A：新用户暂无历史行为时会展示热销兜底商品；若仍为空，请确认商品已上架且库存大于 0。

**Q11：如何查看物流进度？**
A：在「我的订单」中点击「查看详情」，在订单详情页的「物流信息」区查看运单号与物流节点时间线。
