## 1. 模块定位

推荐引擎是「智能特性一：个性化推荐」的核心计算模块，负责把用户历史购买记录转化为面向用户端的「猜你喜欢」推荐列表。设计上采用**纯计算引擎 + 数据加载服务分离**的架构：

- **引擎层（engine）**：只做算法计算，不依赖数据库与 Web 层，便于独立单元测试与替换算法。
- **服务层（service）**：从数据库加载购买/热销/候选数据，组装成算法输入，调用引擎后写推荐日志并缓存。
- **接口层（controller）**：对外暴露推荐接口，鉴权后返回推荐结果。

## 4. 评分公式与阈值配置

### 4.1 综合评分公式

对候选商品 `i`，综合得分：

```
score(u, i) = w1 × freq(u,i) + w2 × cf_norm(u,i) + w3 × hot(i)
```

| 符号 | 含义 | 计算方式 |
|---|---|---|
| `freq(u,i)` | 购买频次得分 | `c(u,i) / max_{j} c(u,j)`，`c(u,i)` 为用户 u 购买商品 i 的次数 |
| `cf_norm(u,i)` | 协同过滤得分（极差归一化后） | `cf(u,i) = Σ_{v∈N(u)} sim(u,v)·r(v,i) / Σ sim(u,v)`，再做 min-max 归一化 |
| `hot(i)` | 近 30 天热销度 | `s(i) / max_{j} s(j)`，`s(i)` 为商品 i 近 30 天销量 |
| `w1, w2, w3` | 三项权重 | 默认 `0.5 / 0.3 / 0.2`，可配置 |

其中 `r(u,i) = 1 + ln(c(u,i))` 用于抑制高频偏差；相似度采用余弦相似度：

```
sim(u, v) = (Σ_{i∈I(u)∩I(v)} r(u,i)·r(v,i)) / ( sqrt(Σ r(u,i)²) · sqrt(Σ r(v,i)²) )
```

### 4.2 阈值与配置项（application.yml）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `recommendation.weight-frequency` | 0.5 | 购买频次权重 w1 |
| `recommendation.weight-cf` | 0.3 | 协同过滤权重 w2 |
| `recommendation.weight-hot` | 0.2 | 热销度权重 w3 |
| `recommendation.top-k-similar` | 20 | 相似用户 Top-K |
| `recommendation.default-limit` | 10 | 默认返回条数 N |
| `recommendation.max-limit` | 50 | 单次返回上限 |
| `recommendation.cache-ttl-minutes` | 30 | 结果缓存 TTL（分钟） |
| `recommendation.purchase-window-days` | 180 | 历史购买统计窗口（天） |
| `recommendation.hot-window-days` | 30 | 热销统计窗口（天） |

### 4.3 候选过滤规则

候选商品必须同时满足：`status = 1`（上架）、`stock > 0`（有库存）、剩余保质期 `> 1` 天。已购商品不参与协同过滤候选，但保留在频次得分中。

## 5. 推荐日志表设计

表名 `recommendation_log`，用于记录每次推荐结果及算法来源，支撑推荐效果复盘与审计。

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 记录 ID |
| user_id | BIGINT UNSIGNED | 否 | - | 用户 ID |
| product_id | BIGINT UNSIGNED | 否 | - | 推荐商品 ID |
| score | DECIMAL(10,4) | 否 | - | 综合推荐得分 |
| source | VARCHAR(32) | 否 | - | 算法来源：`FREQUENCY`/`CF`/`HOT`/`MIXED` |
| algorithm_version | VARCHAR(32) | 是 | - | 算法版本 |
| scene | VARCHAR(32) | 是 | - | 推荐场景：`HOME`/`DETAIL`/`CART` |
| create_time | DATETIME | 否 | CURRENT_TIMESTAMP | 推荐时间 |

索引：`PRIMARY KEY(id)`、`KEY idx_user(user_id)`、`KEY idx_create_time(create_time)`、`UNIQUE KEY uk_user_product(user_id, product_id)`。

建表脚本见仓库 `sql/init.sql` 第 17 张表。
