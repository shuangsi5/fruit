## 1. 算法定位

个性化推荐是本系统的「智能特性一」，目标是为每个用户生成一份「猜你喜欢」列表。系统采用**混合推荐（Hybrid Recommendation）**策略，融合三种信号以在数据稀疏的水果电商场景下保持可解释性与鲁棒性：

1. **购买频次（Frequency）**：用户自己的历史口味偏好。
2. **协同过滤（User-Based CF）**：相似用户的交叉偏好。
3. **热销度（Hot）**：近期全站热门商品，同时承担冷启动兜底。

## 2. 算法输入

| 输入 | 来源 | 说明 |
|---|---|---|
| 用户×商品购买次数 | `orders`（近 180 天，状态 1/2/3）+ `order_item` | 构建 `userId -> (productId -> count)` 交互矩阵 |
| 近 30 天商品销量 | `orders`（近 30 天）+ `order_item` | `productId -> sales` |
| 候选商品 | `product`（`status=1`）+ `inventory`（`stock>0`） | 过滤已下架、售罄、剩余保质期 ≤ 1 天 |

## 3. 评分模型

### 3.1 交互评分（抑制高频偏差）

为避免高频购买用户主导相似度，交互强度采用对数衰减：

```
r(u, i) = 1 + ln(c(u, i))
```

其中 `c(u,i)` 为用户 u 购买商品 i 的次数；`c ≤ 0` 时 `r = 0`。

### 3.2 购买频次得分

```
freq(u, i) = c(u, i) / max_{j∈P(u)} c(u, j)
```

`P(u)` 为用户 u 购买过的商品集合，按该用户的最大购买次数归一化，取值 [0,1]。

### 3.3 User-Based 协同过滤

用户 u、v 的余弦相似度：

```
sim(u, v) = (Σ_{i∈I(u)∩I(v)} r(u,i)·r(v,i)) / ( sqrt(Σ_{i∈I(u)} r(u,i)²) · sqrt(Σ_{i∈I(v)} r(v,i)²) )
```

取相似度 Top-K（K=20）且 `sim > 0` 的邻居 `N(u)`，计算目标用户对候选商品 i 的协同得分：

```
cf(u, i) = Σ_{v∈N(u)} sim(u,v)·r(v,i) / Σ_{v∈N(u)} sim(u,v)
```

候选商品要求邻居购买过、而目标用户未购买过。`cf` 再做极差（min-max）归一化得到 `cf_norm`。

### 3.4 热销度得分

```
hot(i) = s(i) / max_{j∈All} s(j)
```

`s(i)` 为商品 i 近 30 天销量，按全站最大销量归一化，取值 [0,1]。

### 3.5 混合综合得分

```
score(u, i) = w1 · freq(u, i) + w2 · cf_norm(u, i) + w3 · hot(i)
```

默认权重 `w1=0.5`、`w2=0.3`、`w3=0.2`（可配置）。按 `score` 降序取 TopN（默认 10，上限 50）。

## 4. 冷启动与候选不足处理

- **冷启动**：目标用户无购买记录（`P(u)` 为空）时，跳过频次与 CF，直接按 `hot(i)` 降序返回热销榜，`algorithm=HOT`，理由固定为「近30天热销商品，适合新用户参考」。
- **候选不足**：老用户候选集不足 N 条时，用热销榜补足（去重），保证推荐位不空缺。

## 5. 推荐理由生成

每条推荐附带可解释理由标签，`buildReason()` 按信号强度组合：

| 触发条件 | 理由片段 |
|---|---|
| 用户购买过该商品 | 「你常购买该类商品」 |
| `cf_norm > 0.5` | 「相似用户也喜欢」 |
| `hot > 0.6` | 「近期热销」 |
| 以上均未命中 | 「综合推荐」 |

多个理由片段以分号拼接，帮助用户理解推荐依据（对应 FR-6.1「展示推荐理由」）。

## 6. 缓存与时效

- 缓存键：`reco:{userId}:{scene}`，本地 `ConcurrentHashMap` 实现，TTL 30 分钟。
- 命中缓存直接返回；未命中则计算并写回缓存。
- 失效时机：缓存 TTL 到期，或用户完成新订单/售后变更时调用 `evictUser(userId)` 主动清除。

## 7. 伪代码

```
FUNCTION recommend(user, scene, N):
    N = clamp(N, 1, maxLimit)
    bought = queryPurchases(user, last180Days)     // 近 180 天购买记录
    IF bought IS EMPTY:
        RETURN topHot(N) WITH algorithm='HOT'      // 冷启动兜底
    freq   = computeFrequency(bought)              // 3.2
    sim    = topKSimilarUsers(user, K=20)          // 3.3
    cf     = computeCF(user, sim)
    cfNorm = minMaxNormalize(cf)
    hot    = computeHot(last30Days)                // 3.4
    candidates = filterOnShelfInStockNotExpiring()
    FOR EACH i IN candidates:
        score[i] = 0.5*freq[i] + 0.3*cfNorm[i] + 0.2*hot[i]
        reason[i] = buildReason(freq[i], cfNorm[i], hot[i], bought.contains(i))
    top = sortByScoreDesc(score)[:N]
    IF top.size < N:
        top += topHot(N).filter(not in top)        // 热销补足
    saveRecommendationLog(user, top)               // 写 recommendation_log
    cache(user, scene, top, TTL=30min)             // 写缓存
    RETURN top
```
